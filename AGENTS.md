# Repository instructions

After major changes, regenerate the README showcase image with `npm run showcase:slices`. Inspect `showcase/scene-slices-preview.png` and keep the README's top image linked to `showcase/scene-slices.png`. Include the refreshed images with the change; if generation fails, report it rather than claiming the showcase is current.

Keep the README concise. Use one prominent showcase image at the top, without extra screenshot galleries or promotional copy.
